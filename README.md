Egyptian National ID Information Extractor

A simple C# Console Application that extracts and displays information encoded in an Egyptian National ID number.

Project Overview

This project was developed using C# as a beginner programming project to practice fundamental programming concepts and problem-solving skills.

Features

The program extracts and displays:

* Gender: Identifies whether the person is male or female.
* Date of Birth: Extracts the birth date from the ID number.
* Governorate: Identifies the governorate of birth using its code.
* Serial Number: Extracts the serial number.
* MOE Identification: Displays the MOE identification digit.

Technologies Used

* C#
* .NET
* Console Application

Concepts Applied

* Variables and Data Types
* Conditional Statements (if / else)
* Switch Statements
* Arithmetic Operators
* Type Conversion
* Console Input and Output

How to Run

1. Open the project in Visual Studio or another C# development environment.
2. Run the application.
3. Enter an Egyptian National ID number when prompted.
4. View the extracted information.
